## 🏗️ Arquitetura

Projeto frontend estático:

```
Browser
  │
  ▼
index.html
  ├── Estrutura semântica
  ├── Estilos e componentes visuais
  ├── JavaScript de interação
  └── Assets
```

O workflow `static.yml` pode automatizar a publicação do conteúdo estático.

## 🚀 Execução local

Não há dependências obrigatórias de Node.js.

```bash
git clone https://github.com/RLGOMES92/portfolio.git
cd portfolio
```

Depois, abra `index.html` no navegador ou utilize um servidor local.
