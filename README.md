## 🎯 Visão geral

Site de portfólio pessoal desenvolvido para apresentar competências, projetos e soluções digitais de forma profissional.

O projeto funciona como uma **vitrine comercial**: organiza experiência, tecnologia e projetos em uma experiência visual única para transformar visitantes em oportunidades de contato.

## 💼 Problema de negócio

Profissionais de tecnologia precisam demonstrar capacidade de entrega rapidamente. Um portfólio disperso ou pouco estruturado dificulta a percepção de valor por potenciais clientes e parceiros.

### Solução

Uma interface web responsiva, com identidade visual própria, apresentação profissional, projetos e chamada para contato.

## ✨ Funcionalidades

- Apresentação profissional
- Seção de projetos e cases
- Categorias de tecnologias
- Interface responsiva
- Visual dark inspirado no ecossistema GitHub
- Elementos relacionados a IA
- CTA de contato
- Deploy compatível com GitHub Pages

## 🏗️ Arquitetura

Projeto frontend estático, sem backend obrigatório:

```
Browser
  │
  ▼
index.html
  ├── Estrutura semântica
  ├── Estilos e componentes visuais
  ├── JavaScript de interação
  └── Assets
       └── flyer.png
```

O workflow `static.yml` automatiza o deploy do conteúdo estático.

## 📁 Estrutura

```
portfolio/
├── index.html
├── flyer.png
├── static.yml
├── .gitignore
└── README.md
```

## 🚀 Execução local

Não há dependências obrigatórias de Node.js.

```bash
git clone https://github.com/RLGOMES92/portfolio.git
cd portfolio
```

Depois, abra `index.html` no navegador ou utilize uma extensão de servidor local.

## 🌐 Deploy

O projeto foi estruturado para hospedagem estática. O workflow `static.yml` pode ser utilizado no GitHub Actions para publicação no GitHub Pages.
